# ToolBox 待测项

开发者需手动测试验收的部分。

- [ ] Agent 重新加载后发现 ToolBox 技能
  - 步骤1：重新加载 Agent 技能目录或开启新会话，确认能找到 cli-anything-toolbox。
  - 步骤2：请求“使用 $cli-anything-toolbox，仅查看 ToolBox 支持哪些 CLI 能力”。
  - 预期结果：加载对应技能并调用真实 capabilities list，能看到当前 13 项能力；发现过程不创建待办、不读取截图内容、不启动后台。

- [ ] CLI 后台转界面与待办同步（Light/Dark）
  - 步骤1：退出 ToolBox，使用 CLI 创建测试待办，再正常打开 ToolBox。
  - 步骤2：确认只有一组窗口/托盘图标；分别在 Light/Dark 主题下用 CLI 更新、完成、删除、恢复待办。
  - 步骤3：尝试 host stop；随后通过应用菜单退出，再重新启动。
  - 预期结果：后台启动无窗口，普通启动复用同一实例；待办列表、父子进度和回收站同步；UI 打开时 host stop 返回 CONFLICT，菜单退出可用。

- [ ] CLI 与现有重复提醒、启动参数兼容
  - 步骤1：设置短期重复待办，在后台和界面模式下分别等待触发，检查状态与提醒。
  - 步骤2：向已运行实例传入原有 /C:TODO、截图区域及打开图片参数。
  - 预期结果：重复待办按原规则更新且不重复注册；后台不弹提醒，界面模式提醒正常；原参数行为保持。

- [ ] CLI 同用户访问与实际部署
  - 步骤1：将完整 Release 发布目录放到目标机器，调用能力发现、待办命令和本地 OCR。
  - 步骤2：分别用另一账号及不同提权级别尝试连接，确认访问失败时有明确错误；安装旧版实例运行时再调用新版 CLI。
  - 预期结果：完整目录部署可运行；未授权账号不能访问，旧实例无管道时明确失败；缺 OCR 资源时明确返回引擎不可用，不联网下载。

- [ ] 迷你窗口靠边自动隐藏交互
  - 步骤1：分别将窗口拖到上下左右外侧边缘附近，以及超出工作区超过 12 DIP 的位置后放开；确认静置约 800ms 后先回靠对齐，再连续隐藏。指针留在窗口内时只回靠，移开后才收起；右下角等双边越界时按更深一侧隐藏。
  - 步骤2：在收起过程中移回指针，确认从当前位置立即展开；隐藏后快速扫过 12 DIP 握柄不展开，悬停约 120ms 或点击可展开且不主动抢键盘焦点。
  - 步骤3：打开待办详情、快速添加或右键菜单后移开鼠标，确认不误收起；关闭交互后再移开可收起。
  - 步骤4：在收起/展开过程中关闭自动隐藏、切换工作台或隐藏/重新显示迷你窗口，确认没有旧回调拉回旧位置、内容不可点击或窗口消失。
  - 预期结果：上下左右外侧工作区边缘均可停靠隐藏，隐藏终点仅对应方向的握柄可见，内容不覆盖任务栏；动画可逆且所有操作收尾一致。

- [ ] 多屏与缩放的停靠位置
  - 步骤1：分别在 100%、150%、200% 缩放显示器的四边拖动并隐藏，包含负坐标副屏和不同缩放的组合；上下停靠时反复折叠待办。
  - 步骤2：在左右及上下排列的两屏内部接缝拖动窗口，再在停靠后改变分辨率、任务栏位置或断开副屏。
  - 预期结果：停靠距离与握柄宽度按 DIP 一致，不滑入邻屏；环境变化后窗口仍在可用工作区且可召回。

- [ ] Light/Dark 动效与系统动画开关
  - 步骤1：在两种主题下连续切换工作台页面和迷你标签，反复折叠/展开待办并悬停/按下主按钮。
  - 步骤2：动画中开始拖动、调整尺寸、切换窗口；在 Windows 关闭动画效果后重复操作。
  - 预期结果：正常模式有短暂淡入、位移、尺寸和状态反馈，无残影或内容截断；关闭系统动画后直接提交最终状态；重复点击当前页面与数据刷新不重播入场动画。

- [ ] OCR 识别正常且无原生崩溃
  - 步骤1：启动 ToolBox，用热键截图并触发 OCR 识别（含中文+英文内容）
  - 步骤2：确认弹出的识别结果内容正确
  - 步骤3：确认输出目录根下存在 msvcp140.dll、vcruntime140.dll、vcruntime140_1.dll
  - 预期结果：Tesseract 引擎正常识别中英文，无 AccessViolationException；调试器附加运行时也不出现原生崩溃

- [ ] 重复待办到点只弹一条通知
  - 步骤1：启动 ToolBox，新建一个"每天"重复、提醒时间设为 1-2 分钟后的待办
  - 步骤2：等待提醒时刻到达，观察右下角弹窗数量
  - 步骤3：将该待办勾选完成，等下一次重置触发，再次观察
  - 预期结果：每次触发每个待办只弹出 1 条通知（重置时弹"已重置"，未完成时弹"今天还没有完成哦"），无连环重复

- [ ] LLM 聊天助手已从各入口移除
  - 步骤1：分别从侧边栏、迷你模式 Tab、托盘右键菜单、工作台 Dashboard 查看
  - 步骤2：确认不再出现"AI 助手/会话/LLM"入口或会话统计卡片；剪贴板/OCR/预览卡无"发送到 AI"按钮
  - 预期结果：所有 LLM 聊天入口均消失，应用可正常启动导航
- [ ] OCR / 选字 OCR 翻译走非 LLM 接口
  - 步骤1：对一段文字执行 OCR，点击"翻译选中"，并将翻译结果粘贴出来
  - 步骤2：执行选字 OCR，点击"翻译"按钮
  - 预期结果：联网时可得到翻译文本并写入剪贴板；断网或接口失败时提示"翻译失败"，应用不崩溃

  - 步骤2：贴图/截图上右键 → "识别待办"

  - 预期结果：节点输出为翻译后的文本

- [ ] 重复待办提醒时间修改生效（正常路径）
